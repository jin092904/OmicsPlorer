# Generated ontology labels

`ontology_labels.json` is a generated local artifact and is ignored by Git. It can be produced by `apps/workers/scripts/backfill_ontology_labels.py` from CURIEs present in a local database.

Before distributing a generated snapshot, record the source ontologies and versions, retrieval date, script commit, checksum, and applicable attribution or redistribution terms. The application-source repository does not provide a frozen ontology snapshot.
