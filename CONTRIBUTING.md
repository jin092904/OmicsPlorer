# Contributing

Small, reviewable pull requests are preferred. Before submitting a change:

1. Do not include credentials, private user data, unpublished queries, database dumps, or third-party datasets that cannot be redistributed.
2. Add or update tests for behavior changes.
3. Run `make lint` and the relevant test targets.
4. Explain any new external data source, model, or service dependency, including its terms and how its version is recorded.
5. State the measurement protocol beside any performance or quality number.

By submitting a contribution, you agree that it may be distributed under the repository's AGPL-3.0-or-later license. A contributor agreement may be required before a contribution can be included in a separately licensed commercial edition.
