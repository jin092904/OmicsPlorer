# Evaluation fixtures

This directory contains small application-development fixtures. It is not the manuscript evaluation package.

- `injection_payloads.jsonl` contains twelve prompt-handling regression cases.
- `labeled_queries.jsonl` is currently empty; it is not evidence of retrieval quality.

Frozen protocols, reviewed relevance judgments, result tables, and analysis code for the paper are maintained in the separate `omicsplorer-reproducibility` repository. Counts and metrics should be reported from the exact frozen files used for a run, not from targets in planning documents.
