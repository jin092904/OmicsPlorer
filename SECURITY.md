# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing exploit details, credentials, private queries, or user data.

The project does not promise a fixed response or resolution time. Acknowledgement and remediation depend on maintainer availability and the severity and reproducibility of the report.

## Supported versions

Before the first tagged stable release, security fixes are applied to the current development branch only. Older commits and local deployments are not maintained as separate supported versions.

## Deployment responsibility

The included Compose configuration is a local reference configuration. Public deployment requires independent review of authentication, secrets management, TLS termination, network exposure, backups, data retention, and applicable institutional policies.
